# Hadeel Lajnef — Portfolio

Personal portfolio website showcasing my work as a Software Engineering student, featuring interactive elements, smooth animations, dark/light mode, and a clean modern design.

---

## Getting Started

### Prerequisites

* Node.js (v16 or higher)
* npm or yarn

### Installation

1. Clone the repository

```bash
git clone https://github.com/had33l/portfolio.git
cd portfolio

```

2. Install dependencies

```bash
npm install

```

3. Set up environment variables

```bash
cp .env.example .env

```

4. Start the development server

```bash
npm run dev

```

5. Build for production

```bash
npm run build

```
